# Pacchetto tipografico italiano — Cormorant Garamond

Questo pacchetto contiene Cormorant Garamond, un carattere serif display di terze parti, qui raccolto per una prova editoriale italiana. Non è una ricostruzione di Arcadian e non riproduce il disegno dell’immagine di riferimento. Mantiene un’atmosfera serif ad alto contrasto, con grazie delicate; le forme delle lettere sono quelle originali di Cormorant Garamond.

## File

- `CormorantGaramond-Variable.ttf` — file installabile per desktop, pesi variabili da 300 a 700.
- `CormorantGaramond-Variable.woff2` — file web compresso.
- `OFL.txt` — licenza completa.
- `cormorant.css` — esempio `@font-face`.
- `specimen.html` — provino con alfabeto, numeri, accenti italiani e pesi.

## Copertura italiana

Maiuscole e minuscole A–Z / a–z e vocali accentate italiane: À È É Ì Ò Ù e à è é ì ò ù. Il font include inoltre numeri e punteggiatura di base.

## Uso e attribuzione

Cormorant Garamond è distribuito sotto SIL Open Font License 1.1. Puoi usarlo, incorporarlo e ridistribuirlo rispettando i termini completi in `OFL.txt`. Il copyright del carattere resta ai suoi autori. Questo pacchetto non trasferisce la titolarità del font e non è una dichiarazione di assenza assoluta di rischi legali.

Autore: Christian Thalmann e Cormorant Project Authors. Fonte ufficiale: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
Progetto originale: https://github.com/CatharsisFonts/Cormorant

## Installazione rapida

- **Windows:** apri il file `.ttf` e seleziona Installa.
- **Sito web:** copia il file `.woff2` accanto al foglio CSS e usa `cormorant.css`.

Per una versione proprietaria che richiami la reference senza riprodurre Arcadian, serve un disegno originale dei glifi e una verifica professionale di somiglianza e diritti prima dell’uso commerciale.
